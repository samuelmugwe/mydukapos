🗄️ Cash Drawer

Cash drawers plug into the receipt printer itself (an RJ11/RJ12 port on the back), not into the computer directly — the printer sends it the "kick open" signal. Bluetooth and USB printer modes trigger this directly. "System print dialog" mode can now trigger it too, but only if your printer's driver is set to raw/"Generic / Text Only" mode (most thermal receipt printer drivers can be) — the kick command rides along inside the printed receipt itself. If your drawer doesn't open in that mode, switch the printer's driver to Generic / Text Only, or use Bluetooth/USB instead for guaranteed support.

Quick answers for the parts of this app that trip people up most. Tap a question to expand it.

💳 How do I get M-Pesa payments actually working?

You need one of two options, set up under ⚙️ Settings → 💳 Payment Gateway:

Option A — Paystack (simplest). Get a secret key (sk_live_... or sk_test_...) from your Paystack dashboard, paste it into "Save Paystack Key", and copy the Webhook URL shown underneath into Paystack Dashboard → Settings → API Keys & Webhooks. That's it — no Safaricom app needed.

Option B — Safaricom Daraja directly. Needs a Daraja app (Consumer Key/Secret), your Paybill or Till Number, and your Lipa Na M-Pesa Passkey. Use "Till Number" as the transaction type if you take payments on a Till, "Paybill" otherwise. The Callback URL is sent automatically with every request — you only need to copy it somewhere if Safaricom specifically asks you to pre-register one.

Once saved, the key/credential boxes disappear and are replaced with a green "✅ Payment configured" notice — that's confirmation it saved, not a sign something's hidden from you. There's no way to view a saved key again afterwards (this is deliberate, for security); to change it, use Reset to clear it and enter the new one.

If both Paystack and Daraja are configured at once, Paystack is used by default — force one specifically with the "Force a specific provider" dropdown at the bottom of that page.

🖨️ Which printer mode should I use, and why won't copies/the drawer work?

System print dialog works with any printer already installed on the device (via USB, network, or Windows/Mac driver) — no pairing needed, but it opens a print preview each time. Bluetooth and USB modes connect directly to a thermal receipt printer and print silently with no dialog at all, once paired/connected in this same Hardware settings page.

Multiple copies: set the number under "Number of Copies Printed per Receipt" — with System mode, all copies go out as ONE print job (one page per copy), so leave your printer driver's own copy count at 1 or you'll get double the copies you expect.

Cash drawer: it's the printer, not the computer, that triggers the drawer — it plugs into an RJ11/RJ12 port on the back of the printer. Bluetooth/USB modes trigger it directly. System dialog mode can too, but only if the printer's driver is set to "Generic / Text Only" (raw) mode — most thermal printer drivers support this in their settings.

Kitchen tickets use whichever printer mode is already selected here — there's currently no support for sending receipts and kitchen tickets to two different physical printers from the same device.

🖨️ How do I stop the print dialog from popping up every time?

No website or installed app — this one included — is allowed to print silently on its own. Browsers require a confirmation dialog every time; that's a security rule the browser enforces, not something any app's own code can switch off. Installing MinimartPOS to the home screen doesn't change this either.

Two real ways around it:

Bluetooth or USB thermal printer (Settings → Hardware) — these never open a dialog at all, since they send print data straight to the printer instead of going through the browser's print system. If you have a compatible thermal printer, this is the real fix.

Launch the browser with the --kiosk-printing flag — the standard trick for silent printing to a normal (non-thermal) printer via System dialog mode. Find the shortcut that installing MinimartPOS created, right-click → Properties, and add --kiosk-printing (with a space before it) to the end of the Target field. Close every open browser window first, then reopen from that shortcut. It'll auto-print to whichever printer is set as the Windows default, with no dialog and no way to pick a different one from the prompt — set the right default printer in Windows first.

📦🛠️ What's the difference between an Item and a Service?

Item — something sold exactly as it is: a bag of rice, a bar of soap. Has its own stock count and shows up in the Sales Counter.

Service — something you charge for without selling a physical unit: key cutting, delivery, installation. A plain service just has a flat price. Tick "Made from components" to link it to a bill of materials instead: add each item it uses and how much one sale uses (fractions like 1/2 work here), and the app then works out cost-per-sale and how many you can currently do from stock automatically. Tick "This is a bundle" instead to sell several items/services together (e.g. Paint + Brush + Roller) at one price — bundle components can be picked from existing stock (so their own stock is deducted correctly when it sells) or typed freely for something with nothing to track. A service is either component-based or a bundle, never both.

🧾 Delete Voided Sales Records

A voided sale or bill in this console's own Daily Sales/Bills is normally kept (struck-through) as an audit trail rather than deleted. This permanently ERASES every already-voided record instead, freeing up the list but breaking that audit trail for good. Only records already marked voided are affected.
